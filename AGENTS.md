# Estándar obligatorio del proyecto georadarchile.cl

Antes de diseñar, redactar o modificar una página, leer completo `docs/CONTRATO_VISUAL_MIGRACION.md`.

## Referencia de calidad aprobada

La página local `/post/georradar-en-mineria-seguridad-antes-de-intervenir/` es el patrón aprobado de calidad editorial, visual y responsive. No debe copiarse mecánicamente, pero todo trabajo nuevo debe alcanzar el mismo nivel de intención, detalle, credibilidad y acabado.

## Reglas no negociables

- Mantener la identidad corporativa-documental de Geo Radar Chile.
- Usar fotografías, radargramas, planos y evidencia real con contexto; nunca estirar imágenes.
- Evitar plantillas genéricas, acumulaciones monótonas de tarjetas y grandes vacíos sin función.
- Preservar el contenido útil, las rutas y el valor SEO existentes salvo instrucción expresa.
- No prometer detección total, identificación automática ni profundidades universales.
- Mantener CTAs consultivos y específicos.
- Diseñar simultáneamente para escritorio, tablet y móvil; no considerar responsive como una corrección posterior.
- Verificar jerarquía, legibilidad, proporciones, enlaces, metadatos y datos estructurados antes de declarar una página terminada.
- No publicar, desplegar, cambiar DNS, modificar Wix ni alterar georadar.cl sin autorización explícita del usuario.
- No hacer commit ni push sin una solicitud explícita.

## Gate de aprobación

Una página solo se considera terminada cuando:

1. Se reconoce inequívocamente como parte de Geo Radar Chile.
2. Iguala o supera el nivel del artículo minero aprobado.
3. Tiene una composición propia adecuada a su propósito, sin romper el sistema compartido.
4. Usa contenido técnico responsable, evidencia y limitaciones cuando corresponda.
5. Funciona entre 320 px y escritorio sin desbordamientos, superposiciones ni texto mal cortado.
6. Conserva la ruta canónica o documenta la redirección necesaria.
7. Pasa la compilación y la validación del proyecto.
8. Se muestra al usuario en vista normal y móvil para revisión.
